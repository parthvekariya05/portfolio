# Parth Vekariya — Portfolio

Modern full-stack developer portfolio built with React + Vite.

## Stack
- React 18 + Vite 5
- Plain CSS (no frameworks)
- Google Fonts: Syne + DM Sans

## Run Locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Deploy to Vercel

1. Push to GitHub
2. Import repo on vercel.com
3. Framework: Vite | Build: `npm run build` | Output: `dist`
4. Deploy ✅
